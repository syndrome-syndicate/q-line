- **Team Name** - Syndrome Syndicate
- **Project overview** - Physical Visualizer for one of the most widely executed surface codes ([[9,1,3]])

- **Quantum computing & Qiskit** - The Surface code is simulated on qiskit and we use a MWPM decoder with pymtahcing from Craig Gidney. The physical visulaizer we built sends snapshots of the current code to the qiskit backened where the differne syndrome measurements and decoding happens and returns the next state of the of the array and displays that. 

- QEC is important, but can be hard to understand. We wanted to build something that other people could use to understand QEC better. 

- **Implementation & results** - Give the user an interactive experience where one could choose to introduce errors at any time to see how they are propagated, fixed, or broken. One can also replay past runs, this can be used to replay runs from different hardware runs to highlight different types of errors which could be hardware-specific.
